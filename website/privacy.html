Privacy policy

Last updated: 13 November 2026

Short version: Go Flow does not collect, upload or sell anything about you. It has no account, no ads and no analytics.

The app

  • Everything Go Flow does (scanning, cleaning, charts, history) happens on your own PC.
  • Go Flow never uploads your files, file names, folder sizes or any other data.
  • Its screen is a local page that only your own PC can open. Other devices and websites cannot reach it.
  • Settings and the history of what was cleaned are saved on your PC, in %LOCALAPPDATA%\GoFlow. You can delete that folder at any time.

When the internet is used

Go Flow itself does not contact any server on its own. A few of its screens ask another service to do something, only when you choose to use that feature, the same as if you did it yourself in Windows Settings or a browser:

  • Updates: asks Windows Update whether updates are waiting (this contacts Microsoft).
  • Virus scan: "Update virus definitions" asks Microsoft Defender to download new definitions (this contacts Microsoft).
  • VirusTotal second opinion: only if you add your own free VirusTotal API key in Settings and press "Check with VirusTotal" on a file. The normal check sends only a SHA-256 fingerprint of that one file to VirusTotal, never its content and never any other file on your PC. If you go on to press the separate "Upload for scanning" button for a file VirusTotal has not seen before, that file's content is sent to VirusTotal. Your API key is stored only on your own PC and is sent only to VirusTotal, never anywhere else.

Microsoft's and VirusTotal's own privacy policies apply to those services.

This website

  • No cookies, no analytics and no advertising or social-media trackers.
  • The site is hosted on GitHub Pages, and the download comes from GitHub Releases. GitHub, like any web host, can see technical details such as your IP address when you visit or download. See GitHub's privacy statement.
  • To show the newest version number, the page asks GitHub's public API for the latest release. Nothing about you is sent beyond a normal web request.
