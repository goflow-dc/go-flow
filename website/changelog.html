Changelog

What changed in each version. Every release, with its installer and checksum, is also on the releases page.

Version 1.2.0

VirusTotal second opinion

  • New: a second opinion from VirusTotal. Check one file against roughly 70 antivirus engines at once, from the Virus scan screen or directly from a Threat Check finding. Needs your own free API key, added once in Settings.
  • Only a SHA-256 fingerprint of the file is sent for the normal check, never the file's content. If VirusTotal has not seen that file before, you can separately choose to upload it (up to 32 MB) — a deliberate extra step, never automatic.
  • Go Flow still has no antivirus engine of its own; this calls VirusTotal's own public service over HTTPS, using the key you provide.

Version 1.1.0

Threat Check

  • New: Threat Check. Looks for signs of trouble a virus scan can miss: protection switched off (antivirus, firewall, Windows permission prompts), odd programs starting with Windows, suspicious scheduled tasks, unsigned programs running from temp folders, disguised files such as invoice.pdf.exe, and a changed hosts file or proxy.
  • It only looks and reports. Each finding has a plain explanation and a safe action, such as scanning the file with Microsoft Defender or turning it off at startup.
  • Recognises the standard EICAR antivirus test file, so you can check that detection works.
  • The duplicate finder no longer changes a file's "last opened" time.

Version 1.0.0

First release

  • Home: a laptop health score, Smart Scan, a storage chart and a live memory graph.
  • Clean: junk cleaner, large file finder, duplicate finder and Downloads tidy-up.
  • Speed: memory boost, startup apps manager and installed programs by size.
  • Security: virus scans with Microsoft Defender, Windows Update status, restore points and low-disk alerts.
  • System: disk, battery and memory health, weekly auto-clean and a history of everything done.
  • Light and dark themes, and protected folders in Settings.
