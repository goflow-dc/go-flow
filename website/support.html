Installing

How do I install Go Flow?
  1. Press Download and open GoFlow-Setup.exe.
  2. If Windows shows "Windows protected your PC", click More info, then Run anyway.
  3. Follow the installer. Go Flow appears in the Start menu.

Needs Windows 10 or 11 (64-bit) and Microsoft Edge, which Windows already includes.

Why does Windows show a warning?

Windows SmartScreen warns about any new app that is not yet signed with a paid code-signing certificate, until enough people have installed it. It is not a sign of a virus. To be sure your download is the real one, compare it with the published SHA-256 checksum: in PowerShell, run Get-FileHash GoFlow-Setup.exe and check the two values match.

It says "An Application Control policy has blocked this file"

Your PC has Smart App Control turned on (Windows Security, App & browser control). It blocks every app that is not signed with a trusted certificate, and there is no "Run anyway" button. Go Flow is not signed yet, so it cannot run on that PC for now.

We do not recommend turning Smart App Control off just for Go Flow. Once it is off, Windows cannot turn it back on without resetting the PC.
My antivirus flagged the installer

Cleaner apps are sometimes flagged by mistake because they delete files and change startup settings. Check the checksum above. If it matches, you can report a false positive to your antivirus maker, and please let us know too.

Using Go Flow

What is safe to clean?

Everything the Junk cleaner lists is safe: temp files, caches and leftovers that Windows and browsers rebuild when needed. Browser passwords, history and logins are not touched. For large files, duplicates and downloads, you choose each file, and they go to the Recycle Bin.

What does "Go Flow (Admin)" do?

It starts Go Flow with administrator rights, which Windows asks you to approve. That adds: cleaning Windows system temp and update folders, creating restore points, changing startup apps that belong to all users, and showing disk temperature.

Does the memory boost really help?

It asks apps to give back memory they are not using, which helps when memory is nearly full. Windows fills memory again over time, so the lasting fix is closing apps you are not using. Go Flow shows which ones use the most.

How do I protect a folder from ever being cleaned?

Open Settings in Go Flow and add the folder under "Protected folders". Its files still show in results, marked "Kept", but cannot be removed.

How do I uninstall Go Flow?

Windows Settings, Apps, Installed apps, Go Flow, Uninstall. Your settings and history stay in %LOCALAPPDATA%\GoFlow; delete that folder too if you want everything gone.
